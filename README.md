# Шахматка — шахматка.москва

Независимое аналитическое медиа о новостройках: в фокусе Москва, в охвате вся Россия.
Контент-маркетинг на основе архива редакции (≈36 тыс. заметок за 10 лет) → платная аналитика по объектам.

## Структура

```
shakhmatka/
├── README.md
├── docs/                 концепция, решения, бренд-гайд
├── prompts/
│   └── editorial.md      редакционный промт (рабочая версия v1.1)
├── scripts/
│   ├── parse_notes.py    экспорт заметок → data/notes.json
│   └── analyze_notes.py  сводка: темы, застройщики, участки
├── data/
│   ├── raw/              (не используется: исходники лежат в tg_parser/output/propertyinsider)
│   ├── entities/         справочники: застройщики, объекты, регионы, темы
│   └── notes.json        разобранные заметки
├── content/articles/     готовые статьи (markdown + frontmatter)
├── brand/                логотип, иконки, токены цвета и типографики
└── site/                 мобильный прототип сайта (HTML/CSS/JS, без сборки)
```

## Как пользоваться

```bash
# обновить разбор архива
python3 scripts/parse_notes.py ~/tg_parser/output/propertyinsider data/notes.json
python3 scripts/analyze_notes.py data/notes.json

# открыть прототип
open site/index.html
```

## Редакционные правила (коротко)

- Материал выходит только от имени «Шахматки». Старое название канала и ссылки на Telegram не упоминаются.
- Партнёрские и рекламные тексты не публикуются.
- Публикуются только проверенные факты. Непроверенное и слухи удаляются.
- Охват — вся Россия, фокус — Москва.
- Судебные риски застройщиков: Мосгорсуд и районные суды (mos-gorsud.ru), ГАС «Правосудие», kad.arbitr.ru, ФССП, Федресурс.

Полный текст — `prompts/editorial.md`.

## Модель данных сайта

| Сущность | URL | Что на странице |
| --- | --- | --- |
| Застройщик | /zastroyshchiki/pik/ | карточка, объекты, суды, статьи |
| Объект | /obekty/volzhskiy-park/ | адрес ЗУ и все названия, стадия, хронология, цены, статьи |
| Регион / район | /moskva/nagatino/ | объекты на карте, КРТ, статьи |
| Тема | /temy/krt/ | статьи |
| Словарь | /slovar/mpt/ | термин, примеры из архива |

Объект идентифицируется по адресу земельного участка, а не по маркетинговому названию ЖК.
