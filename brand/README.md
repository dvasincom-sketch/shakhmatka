# Фирменный стиль «Шахматки» — v3

Основа — стиль проекта Lendora CRM (Behance, использование согласовано с автором), адаптированный под кириллицу и медиа о новостройках. Живой бренд-гайд: `site/index.html#brand`.

## Логотип «Огонёк» (с 13.10.2026)
Слово «шахматка» шрифтом Unbounded 500, переведённое в кривые. Над правой стойкой «ш» горит оранжевая точка — как точка над «i» в этом шрифте: по центру стойки, на 20% крупнее родной (r = 120 при кегле 1000), центр на высоте 730. Других элементов нет: ни клеток, ни домиков.

Смыслы точки: огонёк в окне (найденная квартира), «i» — проверенная справка, точка домена «шахматка.москва» и метка на карте.

Знак для иконок, favicon и аватаров — та же «ш» с точкой.

Цвета: буквы — графит #1B1B1D (на тёмном — #F3F1EC), точка — #FF8A3D (на тёмном — #FF9550). Точка всегда оранжевая; буквы могут быть только графитовыми или светлыми.

Нельзя: перекрашивать или убирать точку, набирать слово живым шрифтом вместо кривых, растягивать, добавлять к логотипу отдельный значок. Минимальная высота логотипа — 16 px, знака — 14 px.

История: «ш» из клеток (v1), «Шахматная башня» — отклонены, читались как шахматная доска и «шашечки такси».

Файлы (собираются командой `npm run brand` в папке `web`; там же генерируется `web/src/lib/logo-paths.ts` — контуры для сайта и админки):
- `logo.svg`, `logo-dark.svg` — логотип для светлого и тёмного фона;
- `logo-mark.svg`, `logo-mark-dark.svg` — знак «ш» с огоньком;
- `favicon.svg` — знак, сам подстраивается под тёмную тему браузера;
- `app-icon.svg` — иконка приложения (знак на графите);
- `og-default.png` — картинка для соцсетей 1200 × 630.

На сайте (`web/public/`): `favicon.svg`, `favicon.ico` (16/32/48), `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `og-default.png`, манифест `/manifest.webmanifest`. Логотип и знак — в админке Payload.

## Что взято из Lendora
- тёплое светлое полотно, белые карточки без рамок с мягкой тенью, радиус 22 px;
- двухтонные заголовки: первая строка графитом, вторая светло-серым, лёгкое начертание;
- крупные лёгкие цифры с серой дробной частью и маленьким знаком единицы (`% 14,25`);
- жёлтые, коралловые и белые статусы-пилюли;
- оранжевая линия графика с мягкой заливкой и подписями-пилюлями на точках;
- градиент «лаванда → персик» для акцентных карточек (подписка, обложки);
- фото с полупрозрачными тегами поверх и круглыми номерами слайдов;
- плавающая панель навигации снизу, активный пункт — чёрная пилюля с подписью.

## Что изменено
- **Шрифт.** Urbanist из Lendora не поддерживает кириллицу. Его роль играет Unbounded Light 300 (заголовки, цифры), текст и интерфейс — Onest.
- **Логотип** свой: «Огонёк».

## Цвета
| Токен | Светлая | Роль |
| --- | --- | --- |
| Графит `--ink` | #1B1B1D | текст, кнопки, пройденные стадии |
| Полотно `--bg` | #FBFAF6 | фон |
| Солнце `--sun` | #FFD54A | текущая стадия, «старт продаж» |
| Апельсин `--orange` | #FF8A3D | линии графиков, акцентные точки |
| Коралл `--coral` | #F0644F | риск, «ушёл из портфеля», «убрано» |
| Лаванда `--lilac` | #DDE1F8 | холодная часть градиента |
| Градиент `--grad` | #E3E5F8 → #EEE8E2 → #FFDF95 → #FFB86A | подписка, обложки |

Тёмная тема — в `tokens.css`.

## Мобильная версия
Одна колонка, поля 16 px; плавающая нижняя панель (4 раздела); горизонтальные ленты карточек со «снапом»; кнопки и пилюли от 44 px в высоту там, где по ним нажимают; цифры табличные; число не отрывается от единицы.

## Голос
Инсайдер с сухой иронией; факт отдельно от мнения; цифры с единицами и датами; без рекламы и слухов.
