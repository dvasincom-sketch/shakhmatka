# Деплой Шахматки на Timeweb Cloud Apps

Сайт собирается из `Dockerfile` в корне репозитория. В контейнере ничего не хранится между деплоями,
поэтому база — управляемый PostgreSQL, фото — S3-хранилище Timeweb.

## Что создать в Timeweb (один раз)

1. **База данных → PostgreSQL** (16). Запомнить хост, порт, пользователя, пароль, имя базы.
   Если приложение и база в одной приватной сети — использовать приватный адрес базы.
2. **S3-хранилище → бакет** (приватный). Ключи доступа — в настройках хранилища.
3. **App Platform → Backend → Dockerfile**, репозиторий `dvasincom-sketch/shakhmatka`, ветка `main`,
   путь до директории проекта — пустой (корень), путь проверки состояния — `/healthz/`.
   Приватную сеть выбрать сразу (потом её не поменять) — ту же, что у базы.

## Переменные приложения

| Переменная | Значение |
| --- | --- |
| `DATABASE_URI` | `postgres://user:password@host:5432/db` |
| `DATABASE_SSL` | `1`, если база требует SSL (для публичного адреса Timeweb — обычно да) |
| `PAYLOAD_SECRET` | длинная случайная строка (`openssl rand -hex 32`), не менять после запуска |
| `S3_BUCKET` | имя бакета, например `a02d5a36-77cf-44a5-b6ef-013bb0485ee0` (как в панели Timeweb) |
| `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` | ключи S3 |
| `S3_ENDPOINT` / `S3_REGION` | `https://s3.twcstorage.ru` / `ru-1` (значения по умолчанию) |
| `SMSRU_API_ID` | ключ API sms.ru — вход читателей по звонку; без него вход только по почте |
| `NEXT_PUBLIC_SITE_URL` | `https://шахматка.москва` (по умолчанию) |
| `PUBLIC_ROBOTS` | `1` — только когда сайт готов к индексации на боевом домене |
| `DB_POOL_MAX` | подключений к базе у сайта, по умолчанию `5` (скрипты при старте берут 2) |
| `JOB_MEMORY_MB` | лимит памяти фоновых скриптов, по умолчанию `640` |
| `MEILI_EMBEDDED` | `0` — не запускать встроенный поиск (экономит память) |
| `SEED_ON_START` | `1` на первый деплой, потом `0` |

## Первый запуск

1. Деплой с `SEED_ON_START=1`: при старте применяются миграции базы, сайт поднимается,
   в фоне импортируются статьи, районы, факты, досье (≈1–2 мин) и словарь. Лог — вкладка «Деплой» / «Логи».
2. Сразу открыть `/admin/` и создать первого администратора (пока его нет, создать может любой).
3. Опубликовать термины словаря в админке (импорт создаёт их черновиками).
4. Поставить `SEED_ON_START=0` и перезапустить: иначе каждый деплой будет перезаписывать статьи из `content/`
   поверх правок в админке. Досье с галочкой «Собрано из архива» перезаписываются всегда, ручные — нет.
5. Привязать домен шахматка.москва (A-запись на IP приложения), SSL Let's Encrypt выпускается автоматически.
6. Когда всё проверено — `PUBLIC_ROBOTS=1`.

## Фото и S3

Все фото (статьи, досье, загрузки из кабинета редакции) хранятся в бакете, а не в контейнере: контейнер при каждом деплое создаётся заново.
Сайт отдаёт их через `/api/media/file/…`, поэтому бакет остаётся приватным.

Проверить, что хранилище подключено:
- `https://шахматка.москва/healthz/` — вторая строка `storage: s3`. Если `storage: disk` — не заданы `S3_BUCKET` или ключи.
- В логе старта: `→ проверка фото: хранилище S3 (<бакет>)` и `✓ фото: на месте N, восстановлено M, …`.
  При первом старте с S3 скрипт `media:restore` сам загрузит в бакет все фото, у которых есть исходник в `content/` (статьи — `content/articles/media/`, досье — `content/objects/media/` и `photos/`).
  Фото, загруженные через кабинет до подключения S3, жили только в контейнере и пропали — их нужно загрузить заново.

## Если сайт не открывается после деплоя

Смотрите логи приложения:
- `Killed` — контейнеру не хватило памяти. Фоновые скрипты ограничены `JOB_MEMORY_MB` (по умолчанию 640 МБ), встроенный поиск — 128 МБ на индексацию. На тарифе меньше 2 ГБ поставьте `MEILI_EMBEDDED=0` (сайт будет искать по базе) или увеличьте тариф.
- `remaining connection slots are reserved` / `too many clients` — база упёрлась в лимит подключений. Пул сайта — `DB_POOL_MAX` (по умолчанию 5), фоновых скриптов — 2. Перезапустите базу в панели Timeweb (это закроет зависшие подключения старых контейнеров), затем приложение.
- Импорт (`SEED_ON_START=1`) нужен один раз на обновление контента: после строки `✓ импорт контента завершён` поставьте `SEED_ON_START=0`. Если оставить 1, каждый перезапуск заново гоняет импорт, и при нехватке памяти контейнер уходит в цикл перезапусков.

## Обновления

- Код: `git push` в `main` → автодеплой. Миграции применяются при старте.
- Изменили коллекции (поля) — перед коммитом создать миграцию (нужен локальный PostgreSQL):
  `DATABASE_URI=postgres://… npx payload migrate:create имя` → закоммитить `web/src/migrations/`.
- Новый контент из `content/` (статьи, досье): закоммитить и один деплой с `SEED_ON_START=1`.

## Локально

Без `DATABASE_URI` сайт работает на SQLite-файле `web/shakhmatka.db`, схема подтягивается сама, фото — в `web/media/`.

## Поиск (Meilisearch)

Сайт ищет через Meilisearch, если заданы переменные; без них — по базе, как раньше (подсказки в шапке тогда не показываются).

1. Поднимите Meilisearch v1.12 отдельным приложением в Timeweb App Platform (Docker-образ `getmeili/meilisearch:v1.12`) или на облачном сервере:
   - переменные контейнера: `MEILI_MASTER_KEY=<длинный случайный ключ, от 16 байт>`, `MEILI_ENV=production`, `MEILI_NO_ANALYTICS=true`;
   - порт 7700; если у платформы есть постоянный диск — смонтируйте его в `/meili_data` (без диска индекс пропадёт при перезапуске Meilisearch, но сайт пересоберёт его при своём следующем старте).
2. В приложении сайта добавьте переменные:
   - `MEILI_HOST=https://<адрес Meilisearch>` (внутренний адрес сервиса, если платформа его даёт),
   - `MEILI_MASTER_KEY=<тот же ключ>`.
3. Перезапустите сайт. При старте контейнер сам соберёт индекс — в логе строка `✓ поиск: индекс «shakhmatka» … — N документов`.
   Дальше правки в админке (статьи, объекты, застройщики, термины) попадают в индекс сразу, хуками.
   Вручную: `npm run search:index` (в web/).

Что в индексе: опубликованные статьи, все объекты (название, другие названия, адрес участка, застройщик, район, хронология), застройщики, районы, опубликованные термины. Синонимы: ЖК, КРТ, РнС, ГЗК, АГР, ДДУ, МФК, ТПУ; «ё» = «е»; опечатки прощаются в словах от 5 букв.
Ключ Meilisearch в браузер не попадает: подсказки идут через `/poisk/suggest/` на сервере.
