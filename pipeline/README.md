# Конвейер статей из архива

Статьи пишутся партиями по объектам с досье: статья получает хронологию проекта и перелинковку автоматически.

1. `python3 content/archive/build-article-packs.py --batch N --size 30` — отбор заметок (value=article, есть событие в досье,
   кластер заметок об одном объекте за 30 дней = одна статья), пакеты `pipeline/batch-NN/packs/<id>.json` и план `plan.json`.
   Уже написанные статьи и заметки прошлых партий не берутся.
2. Фото заметок партии — в `pipeline/batch-NN/media/` (из `tg_parser/output/propertyinsider/media`).
3. Авторы (по 3 статьи) работают по `pipeline/BRIEF.md` и промту `prompts/editorial.md`: фактчекинг до 6 поисков и 8 страниц на статью,
   выход — `content/articles/<id>-<slug>.md`, проверка `python3 pipeline/check_article.py <статья> <пакет>`.
4. `python3 content/archive/harvest-articles.py` — смены собственников (`ownership_changes`) и текущий застройщик из статей
   переносятся в `content/objects/corrections.json` (там же вручную: район, разделение склеенных проектов `split`),
   затем `python3 content/archive/build-dossiers.py`. Отклонённые статьи (skip: unverifiable) помечают события досье
   «участники рынка говорили … — не подтвердилось».
5. Импорт: `npm run seed:dossiers && npm run seed && npm run seed:dossiers` (в web/, сервер остановлен).
