# Шахматка (шахматка.москва) — контекст проекта

Обновлено: 2026-10-14

## Решения
- Название «Шахматка», домен шахматка.москва. Старое название канала («Недвижимость инсайды») в публикациях не упоминается.
- Фокус — Москва, охват — вся Россия (поле `region` у статьи).
- Партнёрские и рекламные посты не публикуются. Только проверенные факты; непроверенное и слухи удаляются.
- Судебные риски застройщиков: Мосгорсуд и районные суды (mos-gorsud.ru), ГАС «Правосудие», kad.arbitr.ru, ФССП, Федресурс.
- Mobile-first. Светлая тема основная (по умолчанию светлая, переключатель в шапке, выбор в localStorage).
- SEO обязательно для всех материалов (Яндекс в приоритете): семантика, title ≤ 60, description 140–160, H2 как поисковые вопросы, FAQ + JSON-LD, внутренние ссылки, alt.
- Стек сайта: Payload CMS 3.90.2 + Next.js 16 (выбор пользователя), SQLite локально → Postgres в продакшене.
- Статьи «на сверке» индексируются (решение пользователя 13.10): только плашка-предупреждение, noindex не ставим.
- Две даты у материала (решение пользователя 13.10): дата публикации = дата исходной заметки (не меняется никогда, даже для заметок 10-летней давности); дата обновления = дата проверки фактов, текст пишется на эту дату. На сайте видны обе («5 марта 2026 · обновлено 13 октября 2026»), JSON-LD берёт даты из полей статьи (withDates), лента сортируется по дате публикации. Промт v1.5, п. 11a.

Объекты с галочкой «Собрано из архива автоматически» перезаписываются при повторном импорте; после редакторской проверки галочку снять — досье станет ручным. - Страница /signaly/ (в меню): «Сбылось» (сигналы, подтверждённые позже, с опережением в месяцах) и свежие сигналы по месяцам. На 13.10: 924 сигнала по 524 объектам, 29 подтверждены.
