## Часть «population» — население и площадь
Для каждого ключа: население (человек), год/дата оценки, площадь (км²), источник.
- Лучше всего — одна-две сводные страницы, где есть таблица по всем районам сразу: список районов и поселений Москвы в Википедии (ru.wikipedia.org или зеркало), сводки Мосстата/Росстата («Численность населения … на 1 января 2025/2026 года»). Одна таблица = один источник на все районы.
- Бери самую свежую оценку, которая есть в источнике, и записывай её год. Если для части районов в сводной таблице нет данных — отдельные страницы этих районов (WebFetch по ссылкам из таблицы).
- Не смешивай в одном районе население из одного года и площадь из сомнительного источника: у каждого числа своё поле source.

## Часть «transport» — метро, МЦК, МЦД
Для каждого ключа: список станций, расположенных **в границах района** (не «рядом»): название, система (`metro` / `mck` / `mcd`), линии (номер и название, например «1 Сокольническая»; для МЦД — «МЦД-2»), статус (`open`, если открыта на сегодня; строящиеся не бери).
- Источники: списки станций Московского метрополитена, МЦК и МЦД в Википедии — там есть колонка «Район» или «Расположение»; при сомнении — статья станции. Одна таблица на систему.
- Если станция на границе двух районов и источник называет оба — запиши её в оба.
- Станции, которые не удалось однозначно отнести к району, — в отдельный список `unassigned`.
