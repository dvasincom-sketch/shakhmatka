# Районы объектов без адреса — поиск по названию ЖК (бриф)

Вход: `/home/claude/pipeline/districts-fill/resolve-in3-<N>.json` — объекты Москвы без района в досье «Шахматки». У большинства нет точного адреса: есть название проекта (`name`, `aliases`), застройщик, события досье и отрывки заметок (`note_snippets` — черновики редакции, не источник, но в них бывают улица, метро, промзона).
Допустимые ключи районов — `/home/claude/pipeline/districts-fill/districts-list.txt`.

## Задача
Для каждого объекта найти район Москвы по внешнему источнику: карточка ЖК на novostroy-m.ru / cian.ru / domclick / yandex недвижимость, сайт застройщика, mos.ru, stroi.mos.ru, деловые СМИ. В источнике должен быть **адрес с улицей или прямо назван район**.
- **Не больше 1 WebSearch на объект и не больше 38 WebSearch всего.** Запрос — «ЖК <название> <застройщик> Москва район» (или улица из заметки + «Москва»). Часто район виден прямо в сниппете выдачи — тогда WebFetch не нужен. WebFetch — только адреса из выдачи (угаданные дают PROVENANCE_REQUIRED), не больше 1 на объект.
- Сначала объекты, где в названии или заметке есть улица, метро или застройщик + понятное название; объекты с безликими названиями («Участок», «Проект Х», «Жилой комплекс») — в конец.
- Если источник даёт только улицу без района — определи район по улице, только если вся улица (или указанный номер дома) однозначно лежит в одном районе; иначе `district: null` и улица в `evidence`.
- Объект не в Москве (Подмосковье и т. п.) — `region` (`moscow-oblast` или другой slug), `district: null`.
- Не угадывай: нет источника — `district: null`. Поиски кончились — оставшимся `district: null, reason: "не проверено"`.
- Если найденный ЖК явно не тот (другой застройщик, другой город) — не бери.

## Выход
`/home/claude/pipeline/districts-fill/resolve-out3-<N>.json` — массив по всем входным объектам:
`{"slug", "district": "<ключ>" | null, "region": null | "...", "source": "URL" | null, "evidence": "адрес/район как в источнике", "reason": "если null — почему"}`

## Ответ мне
Одной-двумя строками: определено / не определено / другой регион, поисков N.
