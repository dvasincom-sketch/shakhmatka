# Фото для авто-досье (бриф)

На сайте «Шахматки» у досье объекта есть галерея. У этих досье фото пока нет. Тебе — часть досье с картинками из заметок архива редакции.

Вход: `/home/claude/pipeline/dossier-photos/partN.json` — список досье: slug, name, developer, zu, images — до 12 картинок из заметок о проекте (file, дата и начало текста заметки). Файлы: `/home/claude/pipeline/dossier-photos/media/<file>`.

Посмотри каждую картинку (Read). Для досье выбери 1–3 лучших:
- **Брать:** визуализации проекта застройщика или архитектурного бюро; фотографии самого объекта или участка (стройка, здание) — без надписей поверх.
- **Не брать:** скриншоты постов, сайтов, рассылок, карт и сервисов; схемы, таблицы, графики, слайды с текстом; картинки с пометками, стрелками, обводками; коллажи; мемы; документы; фото людей; картинки другого объекта (если по тексту заметки видно, что это сосед или другой проект).
- Сомневаешься, что картинка про этот проект, — не бери. Ничего подходящего — досье без фото, это нормально.
- Первой ставь лучшую (она станет обложкой): визуализация итогового облика или фото готового здания.

Выход: `/home/claude/pipeline/dossier-photos/out/partN.json` — объект `{ "<slug>": {"files": ["<file>", ...], "credit": "визуализация" | "фото"} }` только для досье, где что-то выбрано (`credit` — по первой картинке).

Ответ мне: сколько досье получили фото, сколько картинок выбрано. Одной строкой.
