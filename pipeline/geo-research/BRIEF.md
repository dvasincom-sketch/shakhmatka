# Бриф: адреса объектов «Шахматки»

Ты помогаешь редакции «Шахматки», независимого медиа о новостройках Москвы. Нужно найти **официальный адрес** каждого объекта из твоего списка, чтобы поставить точку на карте.

Вход: TSV-файл со столбцами slug, название, другие названия, застройщик, район, регион, адрес/ЗУ в базе (может быть пустым или неполным), стадия (land — участок, concept, architecture — АГР, permit — разрешение, sales — продажи, completed — сдан).

## Что искать
Для каждого объекта найди адрес, по которому проект однозначно находится на карте: улица и номер дома или владения («Москва, ул. Зорге, вл. 9»). Для Новой Москвы годится «поселение Сосенское, д. Николо-Хованское, …», если там есть улица или ориентир. Если у проекта несколько корпусов, бери адрес первого корпуса или участка.

Источники, по убыванию надёжности:
1. наш.дом.рф (ЕИСЖС): карточка объекта, проектная декларация.
2. mos.ru, stroi.mos.ru, сайт Москомархитектуры, решения ГЗК, ГПЗУ, АГР, реестры (data.mos.ru).
3. Официальный сайт застройщика или проекта (раздел «Контакты», «О проекте», «Расположение»).
4. Каталоги новостроек (ЦИАН, Яндекс Недвижимость, Новострой-М, ДомКлик) — только для адреса, перекрёстно с другим источником, если получится.
5. Деловые СМИ (РБК, Ведомости, Коммерсантъ, Интерфакс-Недвижимость, Москвич Mag, Архи.ру) с адресом участка.

Координаты пиши, **только если источник прямо их указывает** (например, в карточке наш.дом.рф или в ссылке карты на официальном сайте с явными lat/lng). Не выдумывай и не оценивай координаты сам — точку по адресу поставит редакция.

Проверяй, что найденный адрес соответствует району из списка. Если нашёл проект с тем же названием в другом месте — это другой проект, не бери.

Пропускай, не тратя поиски: снесённые/несостоявшиеся проекты без адреса в источниках; объекты, где в базе уже есть адрес и ты не можешь его уточнить (тогда верни адрес из базы с пометкой low).

## Бюджет
До 2 WebSearch (mode "standard") на объект в среднем, WebFetch — по необходимости, всего не больше 120 вызовов на файл.

## Результат
Запиши файл /home/claude/pipeline/geo-research/out-N.tsv (N — номер входного файла) с заголовком:
`slug	address	lat	lng	confidence	source`
- address — «Москва, …» (или «Московская область, …»), без кавычек-ёлочек вокруг всего адреса;
- lat/lng — пусто, если источник не даёт координат;
- confidence — high (официальный источник), medium (каталог/СМИ), low (не уверен);
- source — URL страницы, где ты увидел адрес.
Если адрес не найден: `slug			none		` (address пустой, confidence none).
Каждая строка входа — одна строка выхода, тот же slug.

Ответ: одна строка — сколько найдено high/medium/low/none.
