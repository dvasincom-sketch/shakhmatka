# Разметка новых заметок (бриф)
Прочитай `/home/claude/content/archive/SPEC.md` целиком и выполни его для файла `/home/claude/pipeline/ingest/<to-mark-*.jsonl>`.
Выход — `/home/claude/pipeline/ingest/marked-<те же номера>.jsonl`: ровно одна строка на заметку, в том же порядке, валидный JSON.
Подсказка для `key`: если заметка ссылается на прошлые заметки, адреса и названия этих объектов есть в `/home/claude/content/archive/registry.json` (ищи по id заметки или по адресу) — используй то же написание адреса, что там, чтобы досье склеились.
Веб-поиск не нужен. Проверь в конце, что строк столько же, сколько во входе, и каждая парсится как JSON.
Ответ мне: число размеченных заметок и сколько с `value: article`.
