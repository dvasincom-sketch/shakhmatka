# Бриф: статьи рубрики «Интерьер» для «Шахматки» (по мотивам Never Too Small)

«Шахматка» (шахматка.москва) — медиа о новостройках Москвы. Читатель — покупатель или владелец небольшой московской
квартиры (студия 25–30 м², однушка, евродвушка до 45 м²). Редакция договорилась с правообладателем Never Too Small:
можно брать их англоязычные материалы и фото, переводить и АДАПТИРОВАТЬ. Нужен не перевод, а статья «по мотивам».

## Как писать
- Открой исходный пост (WebFetch): вытащи проект, город, площадь (м²), имена дизайнеров/архитекторов/бюро, фотографа (если указан),
  конкретные решения с размерами и материалами, а также URL фото (cdn.prod.website-files.com/...webp) с подписями — что на каждом.
- Заголовок — по-русски, про идею/пользу для читателя, город в заголовке не обязателен. 60–90 знаков.
- Структура: лид-абзац (почему это важно для московской квартиры) → «## Коротко» (3–5 пунктов) → разделы по решениям/помещениям
  (H2 как поисковые вопросы или «Приём N: …») → в каждом разделе абзац **«Для Москвы»** / **«Как повторить»** → чек-лист или таблица →
  «## Вопросы и ответы» (3 вопроса, те же, что в faq шапки) → «## Источники» (нумерованный список, первым — оригинал NTS) →
  последняя строка курсивом: *Материал подготовлен по мотивам публикаций Never Too Small и использует их фото с разрешения правообладателя.*
- Имена: по-русски + латиница в скобках при первом упоминании: «архитектор Мариана Казагранде (Mariana Casagrande)». Бюро — латиницей.
- Объём текста 6–12 тыс. знаков. Тон — живой, конкретный, без воды и рекламы. Не копируй фразы оригинала дословно — пересказывай.
- Московский контекст — обязательно и разнообразно, не повторяй одни и те же факты во всех статьях: типы домов (хрущёвка, сталинка,
  конструктивизм, дореволюционный доходный дом, панель, монолит), районы и места (Хамовники, Замоскворечье, Басманный, Китай-город,
  лофты в бывших фабриках — «Флакон», «Арма», Даниловская мануфактура и т. п., парки, Москва-река, ВДНХ), типовые планировки
  (студия, евродвушка, ниша у входа, лоджия), климат (отопление, зима, короткий световой день). Для городских материалов («My City…») —
  параллели с Москвой: как маленькую квартиру «продолжают» город, парки, кафе, третьи места.
- ФАКТЫ. Всё про проект — из исходного поста. Про Москву: общеизвестное (география, районы, типы домов) можно без ссылки;
  любые цифры, нормы, законы, даты — только проверенные. Используй банк фактов ниже (ссылки уже проверены). Нужен новый факт —
  до 2 веб-поисков на статью (WebSearch mode "standard"), иначе не пиши. Не выдумывай ни цен, ни размеров, ни имён.
- Без упоминаний Telegram, t.me, max.ru. Без «мы писали в канале».

## Файл статьи
`content/articles/interer-2026-10-<slug>.md`, slug латиницей (транслит смысла по-русски, 3–7 слов).
Образец оформления — `/home/claude/scratch/interer/interer-2026-10-kvartira-28-m2-idei-dlya-studii.md` (прочитай целиком).
Шапка YAML строго как в образце: source {date: 2026-10-16, name, url}, status: ready, type: interior, region: moscow, title, slug, lead,
developers: [], objects: [], districts: [], topics: [interer], images (3–8 фото: file "media/ntsm-<короткий-код>-N.webp" — код уникальный
для статьи, alt, caption с проектом/площадью/автором, credit "Фото: Never Too Small" или с фотографом, source_url — точный URL),
seo {title ≤ 60 знаков, description 140–160 знаков, main_query, keywords 4–6}, faq (3), schema (JSON-строка: Article с isBasedOn = URL
оригинала, datePublished/dateModified 2026-10-16, + FAQPage), factcheck (проект из NTS + каждый московский факт со ссылкой, checked: 2026-10-16),
removed: [], editor_notes, date_published: 2026-10-16, date_modified: 2026-10-16, author: "Редакция Шахматки".
В тексте фото вставляй `![alt](media/....webp)` и подпись курсивом ниже. Не бери логотипы, баннеры, рекламу; планы этажей можно.
Внутренние ссылки: обязательно `[«Интерьер»](/temy/interer/)`; можно `/obekty/`, `/novostroyki/moskva/`.
